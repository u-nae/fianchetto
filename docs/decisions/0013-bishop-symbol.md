# 0013 Bishop 커스텀 심볼: 미트라 모양, 폴더는 배지로 구분

- 상태: 확정 (사용자 선택, 디자인 세션 시안 B)
- 날짜: 2026-10-02

## 맥락
트리 행에서 파일 Bishop은 `doc`, 폴더 Bishop은 `folder.badge.gearshape`로 표시돼 앱의 정체성이 드러나지 않았다. 폴더 Bishop은
그룹(`folder`)과도 비슷해 보였다. DESIGN.md 2장은 Bishop 심볼을 테마의 주 표현으로 정했고, 5.2는 그 후보를 남겨 두었다.

## 결정
디자인 세션이 세 시안을 13pt 트리 행과 큰 크기, 라이트와 다크로 렌더링해 보여 줬고, 사용자가 B를 골랐다.

- 모양: 비숍의 머리(미트라)를 크게 그린다. 구슬, 대각선 홈, 받침띠로 이뤄진다. 폴더 Bishop은 미트라를 줄이고 오른쪽 아래에
  폴더 배지를 붙인다.
- 자산: `fianchetto.bishop`, `fianchetto.bishop.folder` Symbol Image Set. 템플릿은 `scripts/design/generate-bishop-symbols.swift`가
  만든다. 선 디자인을 CoreGraphics 윤곽선으로 바꾸고 합쳐 Regular-M 하나만 담는다.
- 트리 행(`NodeRow`)의 파일과 폴더 Bishop 기호를 이 심볼로 바꾼다. 그룹과 웹 링크 기호는 그대로 둔다.

## 대안
- A 전신 실루엣: 체스 말로는 가장 잘 읽힌다. 하지만 폭이 좁아 13pt에서 작고 빽빽해 보였다.
- C 문서·폴더 외곽 안에 작은 비숍: 종류는 바로 읽힌다. 하지만 작은 크기에서 비숍이 뭉개지고, 폴더 Bishop이 그룹 기호와 비슷해진다.
- 시스템 기호 유지: 정체성 표현이 없다.

## 영향
- 굵기 보간이 없다. 굵기를 바꿔도 같은 모양이 그려진다. 트리 행은 기본 굵기만 쓰므로 지금은 문제가 없다.
- 이동 창에서 그룹을 나타내는 `folder` 기호와 빈 화면 기호는 바꾸지 않는다.
- 컴파일된 심볼은 개발 기기에서 11–48pt로 렌더링해 `doc`과 높이와 굵기를 비교했다. 앱 창에서의 실제 모습과 macOS 15 결과는
  확인하지 못했다(W27).
