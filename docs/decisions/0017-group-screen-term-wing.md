# 0017 화면 용어: 가상 그룹은 Wing

- 상태: 확정 (사용자 결정, 2026-10-03). 0006의 "가상 그룹은 그룹" 부분을 대체한다.
- 날짜: 2026-10-03

## 맥락
0006은 Project를 Board, 로컬 연결 항목을 Bishop으로 부르고 가상 그룹은 "그룹"으로 두었다. 실제 앱을 쓰면서
Board·Bishop 사이의 중간 계층만 일반 명사 "그룹"이라 테마와 어긋나 보인다는 의견이 나왔다(사용자). 후보로 Space·Site 같은
공간·진영 의미의 이름을 검토했다.

## 결정
- 화면에서 가상 그룹(Group Node)은 **Wing**이라 부른다. 체스 판의 한쪽 구역(킹사이드·퀸사이드 윙)이며, 피앙케토도 윙에서 펼치는 수다.
  체스를 몰라도 "날개·구역"으로 읽혀 0006의 "체스 규칙을 요구하지 않는다" 원칙을 지킨다.
- 표기는 Board·Bishop과 같이 한국어 문장 안의 영문 고유 용어다. 예: "Wing 추가…", "Wing 제거", "Wing을 자기 안으로 옮길 수 없습니다."
- 코드·데이터 모델·내보내기 형식은 중립 용어 Group을 그대로 쓴다. 화면 용어는 String Catalog에만 둔다(0006 원칙).
- 옛 화면 용어 "그룹"은 화면 문구 검사(`scripts/check-terms.sh`)의 금지 표현에 넣어 다시 들어오지 않게 한다.
- 에이전트 권장안이며 사용자가 채택했다.

## 대안
- Space: macOS의 Spaces(데스크탑 공간)와 혼동된다.
- Site: 웹사이트로 읽혀 웹 링크와 혼동된다.
- Zone: 체스 결이 없어 "그룹"과 같은 문제가 남는다.
- Square(칸): 칸 하나에 말 하나라 여러 항목을 담는 의미와 어긋난다.
- Rank·File: Rank는 순위로 읽히고, File은 실제 파일과 혼동된다.
- Flank·Diagonal: 덜 익숙하거나 메뉴 문구가 무겁다.

## 영향
- String Catalog 키, 메뉴("Wing 추가…"), 시트 제목, 종류 표시, 이동·제거 안내 문구를 바꿨다. UI 테스트의 메뉴 제목도 바꿨다.
- `scripts/check-terms.sh` 필수 용어를 Wing으로 바꾸고 "그룹"을 금지 표현에 넣었다.
- PRD §5 화면 용어 문장, `CLAUDE.md` UI·문구, README, DESIGN.md의 화면 용어를 갱신했다. PRD·TECH_STACK의 "가상 그룹"은
  데이터 모델 개념(Group)을 가리키는 말이라 그대로 둔다.
- 데이터·저장소·내보내기 형식은 바뀌지 않는다.
