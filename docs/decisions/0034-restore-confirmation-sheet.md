# 0034 복원 전 차이 확인은 복원 전용 확인 시트로 한다

- 상태: 확정 (명세 게이트 t-w20-f2dc76d0, Q-W20-1)
- 날짜: 2026-10-13

## 맥락
PRD §6-F는 복원이 "현재와의 차이를 먼저 보여 준다"고만 하고 어떤 화면인지 정하지 않았다. DESIGN.md 16.3은 과거 구성 띠의
'이 구성으로…' 메뉴에 '복원…'(줄임표 = 확인 단계)만 둔다. W19 비교 화면(0024·0027)을 재사용할지, 복원 전용 시트를 둘지에 따라
차이의 표시 방향(이전/이후), 확정 버튼의 위치, 0027이 정한 비교 띠의 의미가 달라진다.

## 결정
'복원…'은 복원 전용 확인 시트 "#n 구성으로 복원"을 연다. 시트는 요약(0027 규칙: '변화 N개 · Board 이름 변경')과 DESIGN.md 19.3 변화
문구의 변경 목록을 보이고, 이전=현재 구성, 이후=복원 결과(#n) 순서로 값을 적는다. '취소'·'복원' 버튼을 두고 '복원'이 기본 버튼(Return),
Esc는 '취소'다. 현재와 같은 구성이면 '현재와 같은 구성입니다'와 '닫기'만 둔다. 시트는 저장된 구성만 쓰고 파일 시스템에 접근하지 않는다.
에이전트 권장안: A (채택 여부: 채택)

## 대안
- W19 비교 화면을 열고 비교 띠에 '복원' 버튼: 화면을 새로 만들지 않지만 0027의 "이전=순번이 작은 쪽" 규칙과 복원 방향(현재 → 과거)이
  어긋나고, 조회 전용이던 비교 띠에 구성을 바꾸는 버튼이 들어가 0027의 비교 중 명령 규칙을 고쳐야 한다.
- 요약만 있는 확인 창: 가장 작지만 어느 항목이 바뀌는지 보이지 않아 PRD §6-F를 최소로만 만족한다.
