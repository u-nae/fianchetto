# 0012 다시 선택: 같은 대상 판정의 식별자 출처와 보관된 Board의 접근 복구

- 상태: 확정 (명세 게이트 t-w15-f51b756f, Q-W15-1)
- 날짜: 2026-10-03

## 맥락
PRD §6-H는 같은 대상의 권한 복구·stale 북마크 갱신은 revision을 만들지 않고, 다른 대상이면 새 reference와 revision을 만든다고 한다.
같은 대상인지는 파일 시스템 식별자로 판정한다(0004). 그런데 "권한 필요"는 보안 범위 해석이 거부된 상태라 기존 대상의 식별자를 읽을 수 없어,
그대로면 다시 선택이 항상 "판정 불가"로 끝나 같은 대상 복구가 일어나지 않는다. 또 0009는 보관된 Board를 읽기 전용으로 정했지만,
PRD §6-H는 읽기 전용인 과거 화면에서도 같은 대상 접근 복구를 허용한다. 보관된 Board의 다시 선택이 막아야 할 편집인지 정하지 않았다.

## 결정
1. 기존 대상 식별자: 기존 참조를 보안 범위로 해석해 얻고, 거부되면 식별자 확인용으로만 범위 없이 다시 해석해 얻는다(W06 원인 분류와 같은 방식).
   그 위치로 파일에 접근하지 않는다. 둘 다 실패하면 식별자가 없으므로 판정 불가다. 이 규칙은 연결 대상 변경(W09) 확인에도 같이 적용된다.
2. 보관된 Board: 다시 선택으로 같은 대상이면 접근 정보만 갱신한다(revision 없음). 다른 대상이거나 판정 불가면 확인 창 없이 보관 안내를 보인다.
   상태 확인·새로고침·접근 정보 갱신도 보관된 Board에서 한다. 에이전트 권장안: A (채택 여부: 채택, 사용자 답변).

## 대안
- 식별자: 경로 비교로 같은 대상을 정한다 — 0004가 경로 동일성만으로 판정하지 않기로 했으므로 기각.
- 보관된 Board: 다시 선택 전체를 막는다 — 단순하지만 자동 접근 정보 갱신과 비대칭이고 과거 화면(W18) 규칙과 달라진다.

## 영향
- W15: 다시 선택은 같은 대상이면 접근 복구, 아니면 W09 확인 창으로 넘긴다. 보관된 Board는 같은 대상 복구만 허용한다.
- W09: "권한 필요" 상태의 Bishop에서도 연결 대상 변경이 같은/다른 대상을 판정할 수 있다.
- W18: 과거 화면의 같은 대상 접근 복구도 이 규칙을 따른다.
- 실제 sandbox에서 범위 없는 해석이 식별자를 돌려주는지는 W27 실제 환경 검증 항목이다.
