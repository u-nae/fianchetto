# 0035 '이 구성으로 복원…'은 파일 메뉴에 둔다

- 상태: 확정 (명세 게이트 t-w20-f2dc76d0, Q-W20-2)
- 날짜: 2026-10-13

## 맥락
CLAUDE.md는 모든 기능을 메뉴·키보드로 접근할 수 있어야 한다고 하고, 0018은 명령을 네이티브 메뉴 막대에 두되 0027의 '이 기록과 비교'처럼
"메뉴 막대에 대상이 없는" 명령만 예외로 한다. DESIGN.md 16.3은 띠의 '이 구성으로…' 메뉴만 적고 메뉴 막대 자리를 정하지 않았다.
복원은 보고 있는 과거 구성이 곧 대상이라 메뉴 막대에 둘 수 있다.

## 결정
파일 메뉴에 '이 구성으로 복원…'을 둔다. 과거 구성을 볼 때만 켜지고(현재 구성·비교 중·보관된 Board에서는 꺼짐) 띠의 '복원…'과 같은
확인 시트(0034)를 연다. 구성을 바꾸는 명령이므로 조회 명령이 모인 보기 메뉴와 구분한다. 에이전트 권장안: A (채택 여부: 채택)

## 대안
- 보기 메뉴에 '현재와 비교' 옆: 찾기 쉽지만 보기 메뉴에 구성을 바꾸는 명령이 들어가 메뉴 성격이 섞인다.
- 메뉴 막대에 두지 않음: 0027 예외와 같은 취급이지만 그 예외의 근거(메뉴 막대에 대상이 없다)가 복원에는 맞지 않아 0018을 어긴다.
