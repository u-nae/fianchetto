# 0004 같은 실제 대상 판정은 파일 시스템 식별자로 한다

- 상태: 확정 (기준 문서 간 공백 해소, 에이전트 위임)
- 날짜: 2026-10-01

## 맥락
PRD §6-B는 대상 교체 시 같은 실제 대상을 재선택하면 revision을 만들지 말고, 경로 문자열만으로 동일성을
확정하지 말며, 판정이 불가능하면 교체로 기록된다고 알리라고 한다. 판정 수단은 정하지 않았다.

## 결정
- `URLResourceValues.fileResourceIdentifier` 와 `volumeIdentifier` 를 함께 비교한다. 둘 다 얻을 수 있고
  같으면 같은 대상이다. 둘 다 얻을 수 있고 다르면 다른 대상이다.
- 둘 중 하나라도 얻을 수 없으면 "판정 불가"로 보고, 확정 전에 대상 교체로 기록된다고 사용자에게 알린다.
- 판정은 확정 시점에만 수행하고 결과를 저장하지 않는다(식별자는 재부팅·볼륨 재연결 후 바뀔 수 있다).
- 판정 로직은 식별자를 입력으로 받는 순수 함수로 두고, 식별자 조회는 Platform 어댑터가 한다.

## 대안
- 표준화한 경로 비교: 심볼릭 링크·대소문자·이동된 대상을 구분하지 못한다(PRD가 명시적으로 배제).
- 북마크 데이터 비교: 같은 대상이라도 북마크 바이트는 달라질 수 있다.

## 영향
- 대상 교체 서비스와 테스트는 같음/다름/판정 불가 세 경우를 다룬다.
