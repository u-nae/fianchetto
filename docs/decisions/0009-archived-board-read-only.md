# 0009 보관된 Board는 읽기 전용이다: 체크포인트 저장도 막는다

- 상태: 확정 (명세 게이트 t-w10-bbcba7a8, Q-W10-1)
- 날짜: 2026-10-02

## 맥락
PRD §6-C는 보관된 프로젝트의 편집을 막고 조회·내보내기·새 프로젝트 생성은 허용한다고만 한다. 구성을 바꾸지 않는 체크포인트 저장이
막아야 할 "편집"인지 정하지 않았다. 근거: docs/PRD.md#c-배치와-제거, 0005(보관된 프로젝트의 편집은 서비스 계층에서 거부).

## 결정
보관된 Board는 읽기 전용이다. 구성 편집(이름 변경 포함)과 체크포인트 저장을 모두 막고, 조회·내보내기·새 Board 만들기만 허용한다.
체크포인트를 남기려면 보관을 해제한다. 에이전트 권장안: A (채택 여부: 채택).

## 대안
- 허용: 체크포인트는 구성을 바꾸지 않는 작업 맥락 기록이므로 보관 중에도 저장한다. 보관 때 마지막 메모를 남기기 편하지만 "보관 = 바꿀 수 없음"의
  예외가 생기고 체크포인트(W22)·내보내기(W24)가 이를 따로 다뤄야 한다.

## 영향
- W10 명세가 보관된 Board의 편집 차단을 따른다.
- W22 체크포인트 저장은 보관된 Board에서 거부한다(작업 항목 갱신).
