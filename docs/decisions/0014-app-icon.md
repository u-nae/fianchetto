# 0014 앱 아이콘: 월넛·아이보리 대각선 면 분할과 미트라

- 상태: 확정 (사용자 선택, 디자인 세션 시안 C)
- 날짜: 2026-10-02

## 맥락
앱에는 아이콘이 없어서 시스템 기본 아이콘이 보였다. DESIGN.md 6장은 모티프 후보 세 가지와 함께 macOS 15에서 보일 이전 형식을
확인하도록 정해 두었다. 이 프로젝트의 deployment target은 macOS 15.0이다.

## 결정
디자인 세션이 시안 네 개를 그렸다. A는 아이보리 바탕과 긴 대각선, B는 체스판 대각선, C는 대각선 면 분할, D는 에보니 바탕과 금빛이다.
네 시안을 256pt와 64·32·16pt, 밝은 배경과 어두운 배경에서 비교했고, 사용자가 C를 골랐다.

- 월넛(`#8A5A2E`)과 아이보리(`#F6F1E7`) 면을 왼쪽 아래에서 오른쪽 위로 가는 긴 대각선으로 나눈다. 피앙케토의 긴 대각선을 뜻한다.
- 가운데 미트라는 Bishop 심볼(0013)과 같은 모양을 채워 그리고, 양쪽 면에서 색이 뒤바뀐다.
- 형식: Asset Catalog `AppIcon` 세트(16–512pt, @1x/@2x)를 쓴다. 빌드 설정은 `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`이다.
  PNG는 `scripts/design/generate-app-icon.swift`로 만든다.

## 대안
- A 아이보리와 긴 대각선: 읽기 쉽지만, 녹색 사선이 금지 표시처럼 보일 수 있다.
- B 체스판 대각선: 체스 느낌은 가장 강하지만, 16–32pt에서 칸 무늬가 뭉개진다.
- D 에보니와 금빛: 어두운 Dock과 다크 모드에서 주변에 묻힌다.
- Icon Composer `.icon`: 새 OS의 다크·틴트 변형을 지원한다. 하지만 macOS 15에서는 쓰이지 않으므로 이전 형식 세트가 어차피 필요하다.
  그래서 첫 버전은 이전 형식 세트 하나로 시작한다.

## 영향
- 개발 기기(macOS 27)에서 빌드한 앱의 아이콘을 `NSWorkspace.icon(forFile:)`로 렌더링해 확인했다. 시스템이 같은 그림에 유리 효과를
  입혔고, 회색 틀에 가두지 않았다. 16pt에서도 대각선과 미트라가 구분된다.
- macOS 15 실기에서의 Dock·Finder 모습은 확인하지 못했다(W27).
- 새 OS의 다크·틴트 아이콘 변형은 없다. 필요해지면 같은 모티프로 `.icon`을 추가한다.
