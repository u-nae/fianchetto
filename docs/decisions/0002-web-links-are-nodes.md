# 0002 웹 링크는 Node로 관리하고 URL을 Node에 저장한다

- 상태: 확정 (기준 문서 간 공백 해소, 에이전트 위임)
- 날짜: 2026-10-01

## 맥락
TECH_STACK 제품 범위는 "관련 웹 링크"를 체크포인트 항목과 나란히 적고, Node 필드 목록에는 URL이 없다.
PRD는 웹 링크를 Node 종류(F02)로 정의하고 웹 URL 변경을 revision 기록 대상(§7)으로 둔다. PRD §6-G는
체크포인트가 revision을 통해 링크 구성을 참조한다고 명시한다.

## 결정
- 웹 링크는 `kind = webLink` 인 Node다. Node는 선택 필드 `url`(HTTP/HTTPS 절대 URL)을 가진다.
  `webLink` 에만 값이 있고 다른 종류에서는 비어 있다.
- `url` 변경은 이름 변경과 같은 구성 변경으로 revision을 만든다. 같은 Node UUID를 유지한다.
- 체크포인트는 웹 링크를 따로 저장하지 않는다. 연결된 revision의 구성으로 참조한다.

## 대안
- 체크포인트에 링크 목록 저장: 구성 이력과 링크가 이중으로 관리되고 비교·복원에서 빠진다.
- URL을 ResourceReference로 저장: 북마크·접근 상태가 없는 링크에 파일 참조 모델을 억지로 적용하게 된다.

## 영향
- TECH_STACK "주요 개념"의 Node 필드와 제품 범위 문구를 갱신했다.
- 차이 비교는 URL 변경을 별도 변경 종류로 분류한다.
