# 0027 구성 비교 화면의 세부 규칙(W19 명세 게이트와 디자인 세션 합의)

- 상태: 확정 (명세 게이트 t-w19-d0312fb7, 디자인 세션·기능 세션 합의)
- 날짜: 2026-10-06

## 맥락
0024와 DESIGN.md 19장이 비교 화면의 구조를 정했고, 메뉴 막대 문구·요약·빈 상태·제거 행 위치 같은 세부는 W19 명세에서 정하기로 했다.
게이트 중 디자인 세션과 맞춘 규칙과, 게이트 뒤 디자인 세션 의견으로 다듬은 표기를 한곳에 남긴다. 디자인 세션이 병합 뒤 DESIGN.md 19장·11장에 반영한다.

## 결정
- 메뉴 막대: 보기 메뉴에 '현재와 비교'(과거 구성을 볼 때만, 비교 중 꺼짐)와 '비교 닫기'(비교 중에만)를 둔다. 이력 행 오른쪽 클릭
  '이 기록과 비교'는 메뉴 막대에 두지 않는 0018의 의도된 예외다. 메뉴 막대에는 '오른쪽 클릭한 행'이라는 대상이 없기 때문이다.
  대체 경로는 행 고르기 → '현재와 비교' → 비교 띠 대상 메뉴다.
- 비교 중 '열기'·'Finder에서 보기'는 비교에서 고른 행을 그 행이 속한 구성의 참조로 실행한다. 보기·탐색·상태 확인 명령은 꺼지고,
  '현재 구성으로 돌아가기'는 비교를 닫고 현재 구성을 보인다. 비교 중에는 과거 구성 띠 대신 비교 띠만 보인다.
- 이전·이후: 진입 명령은 순번이 작은 쪽을 이전으로 둔다. 대상 메뉴에서 고른 순서는 뒤바꾸지 않는다.
- 통합 트리의 제거 행 위치는 결정표 removed_row_placement(명세 run의 W19.decision.yaml)를 따른다.
- 요약: 변화 표시가 붙는 Node 수 N. 접미는 'Board 이름 변경', '순서 변경 N개 숨김' 순서다. N=0이고 Board 이름이 바뀌었으면 '변화 0개'를 쓰지 않는다.
- 빈 상태: 같은 대상은 '같은 구성입니다', 다른 대상인데 차이가 없으면 '변화 없음', 거르기로 행이 모두 빠지면 '표시할 변화 없음'.
- 변화 문구는 19.3 표 순서로 ' · '로 잇는다. 행의 이동 문구는 바로 위 Wing 이름(최상위는 '최상위')이다.
- '변경 내용'의 위치 값은 최상위부터 직접 부모까지 Wing 이름을 ' › '로 잇는다(예: '문서 › 초안 → 최상위').
  명세 예시는 ' / '였으나, 디자인 세션 의견(17.5 경로 막대와 일치, 파일 경로와 구분)으로 게이트 뒤 ' › '로 다듬었다.
- 비교 중 이력 행이나 '현재 구성' 행을 고르면 비교를 닫고 그 구성을 본다. 비교 대상 변경은 대상 메뉴로만 한다.

## 대안
- 메뉴 막대에 '이 기록과 비교'를 둠: 메뉴 막대에서는 대상 행이 없어 '지금 보는 구성과 자기 자신'의 비교가 된다.
- 위치 구분자 ' / ': 파일 경로처럼 읽힌다.

## 영향
- W19 구현(PR 두 개)의 기준이다. DESIGN.md 19.1·19.2·19.4·11.1은 디자인 세션이 병합 뒤 갱신한다.
