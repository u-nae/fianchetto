# 0021 Bishop 용도 아이콘은 구성의 일부다

- 상태: 확정 (사용자 결정, 2026-10-03). 저장 형식 세부는 W29 명세 게이트(t-w29-55ae945a)에서 확정해 아래에 덧붙였다.
- 날짜: 2026-10-03

## 맥락
아이콘 보기(0020)를 정하면서, Bishop마다 용도(문서·데이터·이미지 등)를 골라 미트라에 배지로 보이자는 요구가 나왔다(사용자).
이 값을 화면 설정으로 둘지 구성 데이터로 둘지에 따라 이력·비교·복원·내보내기의 동작이 달라진다. PRD의 납품 범위(F01–F12)에는 없는 기능이다.

## 결정
- 용도는 Bishop(Node `file`/`folder`)의 선택 속성이다. Wing과 웹 링크에는 없다(사용자 결정).
- 구성의 일부다. 바꾸면 편집 연산 하나·revision 하나가 생기고, 원인은 "아이콘 변경"이다. 같은 값으로 바꾸면 무변경이다(PRD §7).
  과거 구성·비교·복원·과거 구성에서 새 Board·내보내기에 함께 따라간다(사용자 결정).
- 저장 키는 안정적인 영문 값이다: `document`, `data`, `image`, `code`, `reference`, `presentation`, `todo`, `design`. 값이 없으면 배지 없음이다.
  화면 문구·기호·합성 규칙은 0022(디자인)를 따르며, 기호가 바뀌어도 저장 키는 바뀌지 않는다.
- 저장 위치: 스냅샷(RevisionModel.snapshotData의 JSON)에 Node 선택 필드를 더한다. 원인은 기존 문자열 칸에 `changePurpose`로 기록한다.
  SwiftData 스키마(VersionedSchema·MigrationPlan)는 바뀌지 않는다. 기존 revision은 필드가 없는 것으로 그대로 읽는다.
- 편집 연산 `changePurpose(nodeID, purpose?)`를 더한다. Bishop이 아니면 거부, 알 수 없는 키는 거부한다. 비교(W16)에 `purposeChanged` 분류를 더한다.
- 보관된 Board에서는 바꿀 수 없다(0009).
- 첫 버전 범위에 넣고, 작업 항목 W29로 W28 다음·W17 앞에 진행한다(사용자 결정).

### 저장 형식 세부 (W29 명세 게이트)
- 스냅샷 JSON 버전을 2로 올린다. 새로 쓰는 스냅샷은 버전 2이고, 버전 1과 2를 모두 읽는다. 버전 1에는 `purpose`가 없으므로 용도 없음으로 읽는다.
  지원하지 않는 버전(3 이상)은 지금처럼 읽기 거부다. 옛 버전 앱이 새 revision을 잘못 읽지 않도록 버전을 올린다.
- 모르는 키는 보존한다. 저장된 스냅샷(새 버전 앱·가져온 데이터)에 앱이 모르는 키가 있으면 그대로 읽고 다시 쓸 때도 남긴다.
  화면에서는 배지 없이 '기본'처럼 보이고 고르는 곳의 체크도 '기본'이다. 편집 연산으로 새로 넣는 키만 알려진 키로 제한한다(`invalid_purpose`).
- 스냅샷 검증: Wing·웹 링크에 `purpose`가 있으면 `purpose_not_allowed`다. 기존 검사(부모, Wing·웹 링크의 금지 필드) 다음에 본다.
- 편집 연산 거부 순서: 대상 없음(`node_not_found`) → Bishop 아님(`not_linked_item`) → 모르는 키(`invalid_purpose`).
- 이동·대상 교체 뒤에도 용도는 그대로다. 비교의 `purposeChanged`는 저장 키를 그대로 비교한다.

## 대안
- 화면 설정으로 저장: 가볍지만 과거 구성·복원·내보내기에 따라가지 않아, 이름처럼 쓰는 사용자 기대와 어긋난다.
- 모든 Node에 허용: Wing·웹 링크의 종류 구분 기호가 흐려진다.
- 첫 버전 뒤로 미룸: 이력·비교 화면을 나중에 다시 손봐야 한다.

## 영향

- W16 차이 분류, 이력 원인 문구(DESIGN.md 16.2), 내보내기·가져오기 형식(W24·W25)에 필드가 더해진다.
- 폴더 Bishop의 종류 문구를 'Bishop · 폴더'로 바꾼다(0022 F1 처리).
- 과거 구성(W18)에서는 고르는 곳이 꺼지고, 내보내기·가져오기(W24·W25)는 Node의 `purpose`를 그대로 옮기며 모르는 키도 보존한다.
