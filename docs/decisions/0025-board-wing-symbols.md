# 0025 Board·Wing 커스텀 심볼: 3×3 체스판과 '폴더 안 두 칸'

- 상태: 확정 (사용자 선택, 디자인 세션 시안)
- 날짜: 2026-10-03

## 맥락
Board는 시스템 `square.grid.2x2`를, Wing은 `folder`를 쓰고 있었다. 두 가지 문제가 있었다.
- Board 기호가 W28 툴바의 '아이콘으로 보기' 버튼과 같은 모양이라 화면 안에서 의미가 겹쳤다.
- Wing의 `folder`는 실제 폴더(파일 종류 모드의 파란 폴더, 폴더 Bishop의 폴더 배지)와 헷갈렸다. 사용자가 Wing으로 옮기면 파일도
  옮겨진다고 오해할 수 있어, 원본을 옮기지 않는다는 원칙과 부딪히는 인상을 줬다.
또 Bishop만 커스텀 심볼이라 화면 톤이 고르지 않았다.

## 결정
디자인 세션이 Board 다섯 안과 Wing 네 안을 실제 크기(사이드바 13pt, 트리 행, 툴바 옆, 아이콘 보기 40pt)와 라이트·다크로 렌더링해
보여 줬고, 사용자가 골랐다.
- Board: `fianchetto.board`. 둥근 사각 윤곽선 안에 3×3 체스판의 다섯 칸을 채운다.
- Wing: `fianchetto.wing`. `folder` 윤곽선 안에 대각으로 놓인 작은 칸 두 개를 넣는다.
- 두 심볼은 Bishop과 같은 생성 스크립트, 격자, 선 굵기, S·M·L 크기로 만든다. 말 실루엣은 Bishop에만 쓴다.

## 대안
- Board 대각선 세 칸: 주사위 3처럼 읽혔다.
- Board 대각선과 양끝 칸: '크기 조절'이나 '편집' 기호처럼 읽혔다.
- Board 4×4 체스판: 체스판다움은 가장 강하지만 13pt에서 칸이 뭉개졌다.
- Board 2×2 체스판: 가장 단순하지만 '대비'나 '무늬' 기호처럼 읽혔다.
- Wing 폴더 + 대각선: 사선이 '금지'나 '없음' 표시처럼 읽혔다.
- Wing 괄호로 묶은 칸: Wing(판의 한쪽 측면)의 뜻과 맞지만, 작은 크기에서 복잡하고 담는다는 느낌이 약했다.
- 시스템 기호 유지: 위의 의미 겹침과 혼동이 남는다.

## 영향
- 화면 코드의 교체(사이드바 Board 행, 경로 막대, 트리 행·아이콘 타일의 Wing, 이동 창)는 W17이 `BoardBrowserView.swift`를 고치는 중이라
  W17 병합 뒤 디자인 쪽 작은 PR로 한다(기능 세션 합의).
- 컴파일된 심볼을 S·M·L과 13·17·40pt, 라이트·다크로 렌더링해 확인했다. 앱 창 안의 모습은 교체 PR에서 확인한다.
- 후속(2026-10-03): 화면 코드를 교체했다. 사이드바 Board 행, 경로 막대, 트리 행과 아이콘 타일(`TileIcon.wing`), 이동 창, 툴바 'Wing 추가'가 대상이다.
